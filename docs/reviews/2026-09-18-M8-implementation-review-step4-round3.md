| Category | Finding | Minimal fix |

| **TEST GAP** | The warning tests do not enforce the full C4 contract per rejection: several only check fragments such as `already known` / `already used`, and do not check the relevant activation ID. | **TEST GAP** | “Failed with a changed effective state” is not actually represented or verified: its fixture lacks `effective`, and the test does not compare the resulting config event metadata. [tst_sessioncontroller.cpp](/home/max/Development/misc/komport-qt6/tests/tst_sessioncontroller.cpp:869) | Add a changed `effective` snapshot and assert it, `applyStatus: "failed"`, groups, then the following error, unchanged through the controller. |
| **DOCUMENTATION** | §7 says a failed open “does not consume an activation,” while ADR-003 requires every failed attempt to consume an activation ID and the implementation now records that fact in its watermark. [SPEC-M8](/home/max/Development/misc/komport-qt6/docs/specs/SPEC-M8-session-transport-foundation.md:286), [ADR-003](/home/max/Development/misc/komport-qt6/docs/architecture-decisions/ADR-003-transport-abstraction-v1.md:55) | Say that it creates no live activation, while its attempt ID is consumed. Also use the approved C5 wording verbatim if exact adoption is required. |

The watermark itself is not bypassable through a known-failed or stale ID: `opened` requires an ID strictly above it, and only the current non-zero live ID admits ordinary observations. Legitimate normal-order paths are accepted: failed attempt → higher successful open, close/reopen, and live configuration transactions. [tst_sessioncontroller.cpp](/home/max/Development/misc/komport-qt6/tests/tst_sessioncontroller.cpp:418), [tst_sessioncontroller.cpp](/home/max/Development/misc/komport-qt6/tests/tst_sessioncontroller.cpp:716), [tst_sessioncontroller.cpp](/home/max/Development/misc/komport-qt6/tests/tst_sessioncontroller.cpp:783). As specified, a queued-late observation of an older activation is deliberately dropped; that policy is already explicit in §13. [SPEC-M8](/home/max/Development/misc/komport-qt6/docs/specs/SPEC-M8-session-transport-foundation.md:420)
