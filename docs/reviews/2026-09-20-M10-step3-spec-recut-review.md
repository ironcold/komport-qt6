Question 1 — singularity: **No.** §5.11 contains the only full authorization mechanism, but the concrete last-delivery priority is still normed in §5.5, and the final-step and delivery-boundary language remains elsewhere. More importantly, §5.11 itself is incomplete because its helper does not norm token/state/position authorization centrally.

Question 2 — A1 purity: **almost, but not yet.** Under the valid-mutation-context precondition, the ordinary state machine, timing, scheduler and steps can be implemented with no identity/snapshot/guard. However, the §5.5 last-delivery `stop() → Finished` statement still requires callback-time special handling and therefore leaks A2 into A1. Remove that outcome from §5.5 (retain only a reference), and A1 is cleanly reviewable.

The named existing tests are correctly A2 in substance; none needs moving to A1. The direct-helper test needs an exception to the §7 classifier, and the two sixth-round cases need names, exact assertions, and §8 inclusion.
