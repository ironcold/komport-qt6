# Documentation Translation Glossary

This glossary governs controlled German-to-English documentation translation.
Keep identifiers, code, paths, commands, values, and quoted UI text unchanged;
translate surrounding prose only. Update this file after a reviewed batch when
a term needs a more precise or stable rendering.

| German source term | Required English |
| --- | --- |
| Zeichensatz | charset |
| Zeichensatz-Uebersetzung | charset translation |
| Rohdatenstrom | raw byte stream |
| Byte-Exaktheit | byte-exactness |
| verlustfrei / verlustbehaftet | lossless / lossy |
| Anwendungs-Beobachtungsgrenze | application observation boundary |
| Draht-Grenze | wire boundary |
| Sitzungsschicht | session layer |
| Sitzungs-Aufzeichnung | session recording |
| passive Wiedergabe / passives Replay | passive replay |

| Quellidentitaet | source identity |

| Nicht im Scope | Not in Scope |
